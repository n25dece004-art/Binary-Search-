# Công cụ minh họa thuật toán Tìm kiếm Nhị phân (Binary Search Visualizer)

## Giới thiệu
Đây là sản phẩm hỗ trợ trực quan hóa thuật toán **Tìm kiếm Nhị phân (Binary Search)**, được phát triển phục vụ cho bài báo cáo môn học **Ngôn ngữ lập trình C++** của nhóm sinh viên Học viện Công nghệ Bưu chính Viễn thông.

Dự án giúp người học hiểu rõ cách thuật toán vận hành thông qua việc đồng bộ hóa giữa:
- **Dữ liệu mảng:** Trực quan hóa quá trình chia đôi không gian tìm kiếm (`L`, `R`, `Mid`).
- **Mã nguồn (Debugger):** Hiển thị từng dòng lệnh đang thực thi (Execution Tracing) trong thời gian thực.

## Thành viên nhóm
- **Trịnh Bùi Đức Cảnh** (N25DECE004)
- **Lý Anh Khoa** (N25DECE018)

## Tính năng nổi bật
- **Mô phỏng từng bước:** Theo dõi cách thuật toán thu hẹp phạm vi tìm kiếm.
- **Debug Mode:** Tự động highlight dòng lệnh C++ tương ứng với bước thực thi hiện tại.
- **Tùy chỉnh tốc độ:** Tích hợp thanh trượt để thay đổi độ trễ linh hoạt.
- **Chức năng tạm dừng:** Hỗ trợ tạm dừng (Pause) để giải thích logic chi tiết.

## Cách sử dụng
1. Truy cập trang web mô phỏng tại: [Dán link GitHub Pages của bạn vào đây]
2. Nhập giá trị số nguyên cần tìm (`X`) vào ô nhập liệu.
3. Nhấn **"Chạy Debug"** để bắt đầu quan sát thuật toán.
4. Sử dụng nút **"Tạm dừng"** để dừng thuật toán tại vị trí mong muốn và giải thích logic.
5. Điều chỉnh **"Tốc độ chạy"** nếu bạn muốn quan sát nhanh hoặc chậm hơn.
